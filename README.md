# Shader Room

3D 模型与 Shader 效果工作台。React + TypeScript + Vite + Three.js，无后端。

## 本地运行

```sh
npm install
npm run dev
```

固定地址 http://127.0.0.1:3012/。端口由 `.codex/dev-service.json` 约定，Vite 使用 strictPort，发生冲突不会递增端口。当前开发服务由 `local-dev-services` detached tmux manager 管理。

```sh
npm run typecheck
npm test
npm run build
```

`dist/` 是构建产物。解码 JS/WASM 与默认 GLB 已包含在 public 中，无 CDN 依赖。导出模型使用物理像素尺寸，跨设备复现时应按文档记录的 viewport 与 pixelRatio 创建渲染器。

## 功能

- 左侧模型 / 效果 Tab；模型宫格与可折叠的点击/拖拽上传区域。
- 默认 Claw、环面纽结、球体、圆角方块。模型自动归一化、居中；拖动旋转、滚轮缩放、自转、姿态控制、视角重置。
- 滚轮、双指捏合与面板「模型缩放」共用 `view.scale`，范围 0.4–2，步进 0.01；相机不再叠加独立缩放。重置视角或切换模型时恢复 1，面板滚动不影响缩放。
- 原版 Claw 十字绣、原始材质、半调网点、像素化和色阶卡通。原始材质保留 GLB 材质/贴图，其中十字绣、网点、像素和卡通采用白色标准材质与后处理。
- 半调网点、像素化和色阶卡通可调暗部颜色、亮部颜色与饱和度。
- 粒子变形：AMS SVG 平面粒子轻微浮动，点击播放后旋转一周，默认从 35° 开始变为当前模型的粒子。完成后停止浮动，可单独开启模型旋转；再次播放反向还原 SVG。支持数量、大小、双色、时长、变形起点、旋转轴、散开幅度和浮动参数。浮动速度默认 0.35，标志粒子缓慢游动并允许轻微溢出，游动幅度可调。
- 两侧浮层可收展；右侧背景 / Shader Tab，固定导出栏。15 个效果分别配套默认背景，切换效果自动应用颜色与网格；支持 8 种通用色、自定义颜色，十字绣默认开启参考网格。窄屏面板互斥展开。
- 背景页提供环境光、主光、补光的开关、颜色和强度；主光与补光可调方位角和高度角。光照实时影响模型，保留当前视角，支持独立重置。
- JSON 下载 / Markdown 复制到剪贴板：背景输出实际 CSS 和当前光照；Shader 输出完整 GLSL、uniforms、当前灯光/材质/解码器配方、模型身份、视角、当前姿态和复现步骤。粒子效果另含 SVG 原文、确定性采样方法、Points Shader、动画时序与稳态快照；动画过程中暂不可导出。两个范围均包含灯光角度设置与对应 Three.js 位置，schema 版本为 1.2.0。

## 上传与复现边界

- 接收 GLB 2.0 与 FBX 7.0+ 静态模型，单文件最大 50 MiB。FBX 保留初始姿态、材质颜色和支持的内嵌图片；不播放动画片段，不加载外部贴图。GLB 必须自包含。支持内嵌纹理，以及 Draco、Meshopt、KTX2/Basis 压缩。GLB 不可引用外部缓冲区或图片；先在建模软件中打包嵌入。
- 文件在浏览器本地校验和加载，不上传到远端。模型列表仅存于当前页面；刷新后用户模型需重新选择。
- 展示静态姿态，不播放 GLB 动画片段。未支持的扩展会显示错误并可切回其他模型。
- 导出的文档不包含 GLB / FBX 二进制。交给 Agent 时需附带对应模型文件；文档记录文件名、字节数和 SHA-256。程序几何有完整创建参数，无需额外模型文件。
- 精确复现截图时关闭自动旋转，使用 `snapshot` 姿态；不能在已包含累计旋转的快照上再次叠加 UI 旋转。

## 来源

`public/models/claw.glb` 直接复制自 ADQclaw 项目的 `adqclaw-web/public/mtl/claw.glb`，SHA-256 为 `c01fc6e429f4d1c0d81c00306858be5451b2d497a009d875890d63b118bc17f5`，140,620 bytes。

十字绣算法来源为 ADQclaw 的 `components/ClawAnimation.tsx`：按物理像素网格中心采样、交叉针脚判定、亮度阈值映射。针脚/高光颜色扩展为可调参数。

`public/decoders` 的 Draco/Basis 运行资产逐字节复制自已安装的 Three.js 0.183.2 发行包；源路径与初始化方式记录在 `SCENE_RECIPE.loaders`。

`public/assets/ams-logo.svg` 来自用户附件 `amsLOGO.svg`，SHA-256 为 `f34ff0bb1a117814ebf87a1db43f3acf78d7eef17098b80edc4753decc8f0ae9`。`particleLogo.ts` 内嵌同一 SVG 以供加载和独立导出，测试核对两者与原始指纹一致。SVG 填充和模型表面按三角形面积采样，使用固定种子保持重复性；逐帧变形由 GPU 完成。

## 铜版雕刻、全息扫描、虹彩金属、边缘溶解

效果库共 11 项，原始材质排在第一位。四个新增效果直接应用于模型网格，保留静态骨骼 / morph / 实例变换，不经过旧的白色材质后处理路径。

- 铜版雕刻：三组交错刻线、纸张颗粒，可调间距、宽度、角度、对比度、纸色和墨色。
- 全息扫描：半透明轮廓、水平扫描线和移动光带，可调颜色、透明度、密度、宽度与速度，可关闭扫描动画。透明画面采用最近表面，直接输出 straight alpha，不叠加背面透明层。
- 虹彩金属：程序化棚拍反射与三色虹彩，可调粗糙度、虹彩强度、颜色和流动速度，可关闭流动。属于设计化金属效果，不依赖 HDR 环境贴图。
- 边缘溶解：定向噪声裁切与亮色边界，支持正向消散、反向还原、手动进度、XYZ 方向、时长、噪声密度、边缘宽度及双色设置。手动进度取消播放；更换模型或效果重置为完整模型。

JSON / Markdown 包含专属 GLSL、uniforms、surfaceRecipe、精确效果时钟和完整溶解播放状态，可导出中间帧。减少动态效果偏好下关闭连续效果动画，溶解直接到终点。模型自转仍由原有模型控制独立管理。

本轮验证：构建通过、64 项测试通过；独立浏览器检查四种效果、溶解消失与反向还原、Markdown 复制成功。实际下载 JSON 验证溶解进度 0.45；分别关闭扫描与虹彩动画后，两次导出的时钟完全一致。Vite 仍有现存大包体提示。

## 效果库与网页吸管

效果库现有 15 项，双列宫格展示预览图、标题和关键词，原始材质保持首位；不显示卡片描述和操作说明行。已撤下后续六项实验效果及对应渲染、调参和导出代码。

颜色控件支持 HEX、调色板和网页吸管。吸管同步捕获当前 WebGL 画面，合成真实背景与网格，隐藏面板后点击模型或背景取色；Esc 取消。直接使用网页画面，不依赖内置浏览器的原生 EyeDropper，也不读取其他应用。

## 图片参考效果

根据四张参考加入几何字符、自适应网格、文字马赛克、像素字符。四者使用独立的中灰材质模型采样 pass，避免过亮输入丢失光影；不会改变既有效果的渲染。

- 几何字符：黄色叉号、空心框和实心块随亮度分布，支持尺寸、笔画、辉光、对比与颜色。
- 自适应网格：固定大网格按轮廓/亮度差最多细分四级，保留连续的蓝紫色影像；格距、阈值、层数、线宽及配色可调。
- 文字马赛克：不同长度词块构成轮廓，支持行高、间隔、标签色、文字色和自定义词库。词库限64词，每词最多24个Unicode字符；空词库回退pixel。
- 像素字符：灰块为主、少量反白/正色字符，提供格距、宽高比、灰阶、亮度、字符占比、扫描纹与颜色。

字符随机变动默认关闭，可开关并调速；关闭和减少动态效果时冻结时钟。自适应网格不使用字符动画。切换效果自动应用配套背景，之后仍可自定义颜色与网格；重置背景恢复当前效果的默认值，重复点击已选效果保留自定义背景。

导出保留独立GLSL、输入材质、CSS像素单位、精确时钟与图集生成配方。文字JSON/Markdown包含实际PNG图集，避免不同设备字体差异；缺少PNG时可按配方重建。四种效果浏览器均正常渲染，无着色器错误；实测词库更新、Markdown复制、图集PNG导出及暂停后连续两次导出tick一致。
